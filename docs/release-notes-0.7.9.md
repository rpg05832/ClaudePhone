# גרסה 0.7.9

**שליחת הודעה לשיחות ענן מהטלפון**
- בלוח הבקרה, "הגדרות ותקינות", כותרת חדשה "שיחות ענן": מוסיפים שיחות מ-claude.ai/code (שם להקראה וקישור לשיחה).
- בטלפון: מקש 8 ("שיחות נוספות"), ואז 2. בוחרים שיחה, מקליטים הודעה, שומעים את התמלול ומאשרים בהקשה על 1. ההודעה נכנסת לשיחה בענן, והיא ממשיכה לעבוד עם כל ההיסטוריה שלה.
- השליחה חד-כיוונית: התשובה מופיעה בשיחה עצמה (באתר, באפליקציה או ב-Desktop). בטלפון נשמע רק "ההודעה נשלחה".
- דורש ש-Claude Code במחשב מחובר לאותו חשבון claude.ai (פקודה חד-פעמית: `claude auth login`). שיחה בארכיון לא מקבלת הודעות.

**אישור פקודות בלי לשמוע את הפקודה**
- ברירת המחדל החדשה: כשקלוד מבקש להריץ פקודה ויש לה תיאור קצר, מוקרא התיאור בלבד. מקש 3 משמיע את הפקודה עצמה לפני האישור (השמעה לא מאשרת). פקודה בלי תיאור מוקראת במלואה כמו קודם.
- אפשר לחזור להקראה מלאה: בלוח הבקרה ("בקשת אישור לפקודה"), או בטלפון: 7, ואז 1, ואז 4.

**מכסה שנגמרה**
- כשמכסת השימוש של Claude נגמרת, המשימה נכשלת בהודעה ברורה בעברית, עם שעת האיפוס אם Claude ציין אותה, במקום הודעת שגיאה גולמית.
