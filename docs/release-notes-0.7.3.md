# גרסה 0.7.3

**תיקונים באשף ההגדרה** (לשתי המערכות, Windows ולינוקס)
- שלב ימות המשיח: אחרי שמירת הטוקן (גם אחרי אישור החלפה של שלוחה קיימת), "המשך" לא התקדם והופיעה ההודעה "מלא שדה זה". תוקן.
- שלב הטלפונים: כשכבר יש מספרים מורשים הם מוצגים (מוסתרים), ואפשר להשאיר, להסיר או להוסיף בלי להקליד הכל מחדש. בלי שינוי, "המשך" עובר הלאה. קוד הכניסה נשאר אם משאירים את השדה ריק.
- מספר טלפון לא תקין מציג הודעת שגיאה, במקום להימחק בשקט.
