# גרסה 0.7.6

**עדכונים משני מקורות: המאגר שלך והמאגר המקורי**
- התוכנה בודקת את ה-Releases של שני מאגרים: המאגר שלך (`shmuel-sinay/ClaudePhone`) והמאגר המקורי של המפתח (`rpg05832/ClaudePhone`), ומציעה את הגרסה הגבוהה מביניהן. בשוויון, נבחר המאגר שלך.
- כך אפשר לערוך ולפרסם גרסאות משלך, ועדיין לקבל את העדכונים של המפתח המקורי. כדי שעדכון של המקורי לא ידרוס את השינויים שלך, מאחדים אותו למאגר שלך (merge) ומפרסמים גרסה גבוהה ממנו.
- אם אחד המאגרים לא עונה, הבדיקה ממשיכה עם השני.
- בלוח הבקרה, "הגדרות ותקינות": שדה נוסף "המאגר המקורי של המפתח", ולצד הגרסה מוצג מאיזה מאגר היא באה. אפשר לרוקן את השדה כדי לקבל עדכונים רק מהמאגר שלך.
