# גרסה 0.7.6

**עדכונים רק מהמאגר שלנו, ואוטומטיים**
- התוכנה בודקת עדכונים רק ב-`shmuel-sinay/ClaudePhone`, ולא במאגר המקורי.
- עדכון אוטומטי פועל כברירת מחדל (רק כשאין משימה פעילה ואין שיחת טלפון). אפשר לכבות בלוח הבקרה, "הגדרות ותקינות".

- סקריפט חדש `enable-boot-start.ps1` בתיקיית ההתקנה: מריצים פעם אחת כמנהל, מזינים את סיסמת Windows, והסוכן (רק הוא) עולה עם הפעלת המחשב גם בלי להיכנס למשתמש. ביטול: `-Remove`.
