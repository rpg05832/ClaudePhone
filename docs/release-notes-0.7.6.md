# גרסה 0.7.6

(לפי הערות של עידו300 בפורום)

**שם פרויקט בקול, בלי יחידות**
- שם פרויקט חדש שנאמר בקול תומלל עד עכשיו בזיהוי הדיבור של ימות, שעולה יחידות. מעכשיו ההקלטה מתומללת כמו שאר ההקלטות, במתמלל של התוכנה (Claude או ivrit-ai), בלי עלות. השם מוקרא לאישור כמו קודם.

**כניסה בלי קוד אישי (לבחירה)**
- בלוח הבקרה, "הגדרות ותקינות": "לדרוש קוד אישי בכניסה מהטלפון". כשמבטלים, מספר מורשה נכנס ישר לתפריט לפי זיהוי השיחה. ברירת המחדל נשארת: קוד נדרש. ההגדרה נמצאת רק בלוח הבקרה, לא בטלפון.
- שים לב: בלי קוד, כל מי שמחזיק בטלפון מורשה שולט במחשב. הקוד עצמו נשמר, ואפשר להחזיר את הדרישה בכל רגע.
