- אפשר להגדיר בקובץ ההגדרות (`github.quick`) עד שישה מאגרים עם שם להקראה בעברית. בתפריט "פרויקט חדש" הם מקבלים את המקשים 4 עד 9 ונפתחים ישירות, בלי לעבור על כל הרשימה.
- דוגמה: `"github": { "quick": [ { "fullName": "owner/repo", "spokenName": "השם בעברית" } ] }`.
