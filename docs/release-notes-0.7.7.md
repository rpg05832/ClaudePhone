# גרסה 0.7.7

**פרויקטים ממאגרי GitHub, מהטלפון**
- בלוח הבקרה, "הגדרות ותקינות", כותרת חדשה "GitHub": מדביקים טוקן גישה (Personal access token), והתוכנה בודקת אותו ושומרת אותו רק במחשב (`data\github.token`).
- בטלפון, בתפריט "פרויקט חדש" (מקש 3, ואז 1) מופיעה אפשרות חדשה: מקש 3, "מאגר מ-GitHub". התוכנה מקריאה את המאגרים שלך מהעדכני לישן (תשעה בעמוד, סולמית לעמוד הבא), ומה שבוחרים משוכפל לתיקיית הפרויקטים ונפתח כפרויקט. מאגר שכבר שוכפל מתעדכן (`git pull`) לפני העבודה.
- אפשר לדחוף: הטוקן לא נרשם בכתובת המאגר, אלא ב-credential helper מקומי שקורא אותו מהקובץ. כדי לדחוף צריך טוקן עם הרשאת Contents: Read and write.
- בלי טוקן, האפשרות לא מופיעה בתפריט.
