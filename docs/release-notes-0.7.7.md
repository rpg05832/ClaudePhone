# גרסה 0.7.7

**שרת עם כתובת ציבורית משלו (בלי מנהרה)**
- באשף, בשלב "ימות המשיח": "איך ימות מגיעים למחשב הזה?". ברירת המחדל נשארת מנהרת Cloudflare אוטומטית (למחשב ביתי). לשרת עם דומיין ו-https אפשר לבחור "כתובת ציבורית משלי": השלוחה בימות נרשמת ישר לכתובת, אין מנהרה, ורכיב cloudflared לא נדרש. הנתיב שימות פונים אליו מקבל חלק אקראי (הסוד). הסבר, דוגמאות ל-Caddy ול-nginx ושורת בדיקה חדשה ב-`docs/linux.md`.
- בלוח הבקרה השורה "מנהרה" הופכת ל"כתובת ציבורית" במצב הזה, עם הכתובת המלאה.

**נעילה תקועה של Claude Code**
- נמצא אצל משתמש: תיקיית `.claude.lock` עם קובץ בפנים (מתוכנת גיבוי או סנכרון) מנעה מ-Claude Code לחדש את ההתחברות, וכל משימה נכשלה ב-"OAuth access token has expired", בלי הודעה ברורה. התוכנה בודקת את זה בהפעלה וכל שעה, מזיזה נעילה כזאת הצידה (שינוי שם, לא מחיקה) ורושמת ביומן ובלוח ("Claude Code: נעילה תקועה הוזזה הצידה"). בדיקת המחשב באשף מציגה נעילה כזאת אם נשארה.
