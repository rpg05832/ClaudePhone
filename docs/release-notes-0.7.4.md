# גרסה 0.7.4

**תמלול דרך Claude, בלי התקנה**
- ההקלטות מהטלפון מתומללות עכשיו בשירות ההכתבה של Claude, אותו שירות שכפתור המיקרופון ב-Claude Code משתמש בו, עם ההתחברות של Claude Code שכבר יש במחשב. לא צריך Python, faster-whisper או מודל, והתמלול לא נספר במכסת השימוש. בבדיקה על הקלטות אמיתיות: עברית מדויקת, 7 עד 10 שניות להקלטה.
- ivrit-ai (התמלול במחשב) נשאר כגיבוי: כשהשירות של Claude לא עונה, לא מזהה דיבור, או נתקע וחוזר על אותה מילה, ההקלטה מתומללת אוטומטית במחשב, אם ivrit-ai מותקן. אפשר גם לבחור ב-ivrit-ai כמנוע הראשי, ואז Claude הוא הגיבוי.
- הבחירה: בלוח הבקרה, "הגדרות ותקינות", "תמלול ההקלטות"; או בטלפון, מקש 7 ואז 8. שורת המצב מראה איזה מנוע פעיל ומה הגיבוי.
- באשף ההגדרה, Python, faster-whisper ומודל ivrit-ai הם עכשיו רשות (גיבוי). התקנה חדשה עובדת בלי להוריד את 1.7 GB של המודל. התקנות קיימות ממשיכות כרגיל, והגיבוי כבר מותקן בהן.
- הרעיון והפרוטוקול מהפרויקט claude-code-yemot-hooks של zevisvei.
- בעזרה: פרק על התמלול.
