# גרסה 0.7.2

**חדש: גרסה ללינוקס**
- התוכנה זמינה עכשיו גם בלינוקס: כל הפצה רגילה, x64 או arm64, במחשב עם מסך או בשרת בלי מסך. התקנה בפקודה אחת, בלי sudo:
  `curl -fsSL https://github.com/rpg05832/ClaudePhone/releases/latest/download/install.sh | bash`
- הוראות מלאות, ההבדלים מ-Windows ורשימת בדיקות: `docs/linux.md` במאגר. גרסת הלינוקס חדשה: חלק מהדברים עוד לא נבדקו על מחשב לינוקס אמיתי (עלייה עם הפעלת המחשב, שולחן עבודה, שיחת טלפון אמיתית), ולכן כדאי לעבור על רשימת הבדיקות.

**הדפדפן שלך במשימות מהטלפון (Claude in Chrome)**
- משימה מהטלפון יכולה לעבוד בתוך Chrome הרגיל שלך, עם החשבונות שאתה כבר מחובר אליהם, כולל מעבר בין חשבונות Google שמורים. דורש את התוסף Claude in Chrome.
- מפעילים בלוח הבקרה: "הגדרות ותקינות", "חיבורי MCP למשימות מהטלפון", "הדפדפן שלך".
- בחירת הדפדפן (כשיש כמה פרופילים של Chrome): הראשון ברשימה (ברירת המחדל), דפדפן מסוים, או "לשאול אותי בטלפון בכל משימה". הכפתור "רענן רשימת דפדפנים" בודק מה מחובר.
- Claude עובד בלשוניות חדשות בקבוצה משלו ולא נוגע בלשוניות שלך.
- הרשאות: פתיחת דף, קריאה וצילום מסך רצים לבד; לחיצה, הקלדה ומילוי טופס מוקראים לאישור במצב "שינויים, פקודות באישור", רצים לבד ב"אישור אוטומטי" ונחסמים ב"קריאה בלבד". Claude לא מקליד סיסמאות, קודי אימות או פרטי תשלום.

**תיקונים**
- התקנת התמלול בהתקנה חדשה: גרסה חדשה של רכיב (PyAV 19) שברה את פענוח השמע. ההתקנה נועלת עכשיו גרסה שעובדת. התקנות קיימות לא מושפעות.
- סריקת החיבורים ממתינה כראוי לשרתים איטיים.
- בעזרה: פרק על הדפדפן.
