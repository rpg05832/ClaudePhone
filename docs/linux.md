# Claude בטלפון בלינוקס: התקנה ובדיקה

גרסת הלינוקס חדשה (מגרסה 0.7.2). היא נבדקה בשרת Ubuntu בלי מסך, אבל כמה דברים עוד לא נבדקו על מחשב לינוקס אמיתי. הרשימה למטה מסבירה מה לבדוק ואיך.

## מה צריך לפני ההתקנה
- הפצת לינוקס רגילה (Ubuntu, Debian, Mint, Fedora וכדומה), 64 ביט: x64 או arm64. Alpine לא נתמך.
- `curl` ו-`tar` (קיימים כמעט בכל הפצה).
- systemd (קיים כמעט בכל הפצה). בלעדיו התוכנה עובדת, אבל לא עולה לבד עם הפעלת המחשב.
- מנוי Claude (Pro או Max). ההתחברות נעשית באשף ההגדרה.
- **בנטפרי:** תעודת האבטחה של נטפרי צריכה להיות מותקנת במערכת (כמו בכל תוכנה אחרת בלינוקס). אחרת ההורדות בהתקנה ייכשלו.
- אין צורך ב-sudo, ב-Python או ב-Node: הכל מותקן בתוך תיקיית התוכנה. התמלול נעשה דרך Claude בלי התקנה; תמלול במחשב (ivrit-ai) הוא גיבוי רשות.

## התקנה
פותחים טרמינל ומריצים:
```
curl -fsSL https://github.com/rpg05832/ClaudePhone/releases/latest/download/install.sh | bash
```
ההתקנה:
1. מורידה את הקובץ המתאים למחשב (x64 או arm64) ובודקת את טביעת האצבע שלו.
2. מתקינה לתיקייה `~/.local/share/claudephone`.
3. רושמת שירות systemd של המשתמש, כדי שהתוכנה תעלה עם הפעלת המחשב.
4. פותחת את אשף ההגדרה בדפדפן.

אם מופיעה ההודעה "כדי שהסוכן יעלה גם בלי להתחבר למחשב", מריצים פעם אחת את הפקודה שהיא מציגה (`sudo loginctl enable-linger ...`). זה חשוב בעיקר בשרת.

**בשרת בלי מסך:** ההתקנה מדפיסה פקודת SSH וכתובת. מריצים את פקודת ה-SSH במחשב שלך, ופותחים את הכתובת בדפדפן שלך. ההתחברות ל-Claude באשף עובדת גם שם: מופיע קישור, מאשרים אותו, ומדביקים את הקוד.

## פקודות שימושיות
| מה | פקודה |
|---|---|
| מצב השירות | `systemctl --user status claudephone` |
| הפעלה מחדש | `systemctl --user restart claudephone` |
| עצירה | `~/.local/share/claudephone/stop.sh` |
| יומן התוכנה | `tail -f ~/.local/share/claudephone/agent/data/agent.log` |
| הסרה (שואלת אם למחוק גם את ההגדרות והנתונים) | `~/.local/share/claudephone/uninstall.sh` |

## איך ימות מגיעים לשרת: מנהרה או כתובת משלך
ימות המשיח צריכים לפנות לתוכנה דרך האינטרנט. יש שתי דרכים, ובוחרים ביניהן באשף, בשלב "ימות המשיח" (אפשר לפתוח את האשף שוב מהלוח בכל זמן):

**מנהרה אוטומטית (ברירת המחדל).** התוכנה פותחת מנהרת Cloudflare (`cloudflared tunnel`) ומקבלת כתובת `https://....trycloudflare.com`. ימות פונים לכתובת הזאת, ו-Cloudflare מעביר את הבקשה למחשב דרך חיבור יוצא שהתוכנה פתחה. בלי פתיחת פורטים, בלי דומיין, בלי חשבון Cloudflare, חינם. הכתובת מתחלפת בכל הפעלה, ואחרי כל התחברות התוכנה מעדכנת את השלוחה בימות לבד. Cloudflare הוא רק צינור: הוא לא רואה את ההקלטות (החיבור מוצפן), ושום דבר לא עובר דרך שרת של מישהו אחר. זאת הדרך הנכונה למחשב ביתי מאחורי ראוטר או נטפרי, והיא עובדת גם בשרת.

**כתובת ציבורית משלך.** לשרת שיש לו דומיין ותעודת https. בוחרים באשף "כתובת ציבורית משלי" ומקלידים את הכתובת (למשל `https://claude.example.co.il`). אז אין מנהרה, ורכיב cloudflared לא נדרש: השלוחה בימות נרשמת ישר לכתובת שלך, והתוכנה מציגה את הכתובת המלאה שימות יפנו אליה, בצורה `https://claude.example.co.il/yemot-<16 תווים אקראיים>`. החלק האקראי הוא הסוד שמבדיל בין בקשות של ימות לכל אחד אחר (במנהרה הכתובת עצמה אקראית), אז לא לפרסם אותו.

התוכנה מאזינה רק מקומית, ב-`127.0.0.1:7789`, ולכן צריך reverse proxy עם https לפניה. למשל ב-Caddy (מסדר תעודה לבד):
```
claude.example.co.il {
    reverse_proxy 127.0.0.1:7789
}
```
או ב-nginx (עם תעודה, למשל מ-certbot):
```
server {
    listen 443 ssl;
    server_name claude.example.co.il;
    ssl_certificate     /etc/letsencrypt/live/claude.example.co.il/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/claude.example.co.il/privkey.pem;
    location / { proxy_pass http://127.0.0.1:7789; }
}
```
בדיקה: בלוח הבקרה, "הגדרות ותקינות", השורה "כתובת ציבורית (בלי מנהרה)" ירוקה, ובשיחה לשלוחה נשמע התפריט. אם ימות מחזירים שגיאה, בודקים שהדומיין מגיע לשרת (`curl -I https://claude.example.co.il/` מחזיר תשובה מהתוכנה, 404 זה בסדר) ושהתעודה תקפה.

מי שמעדיף להגדיר בקובץ: ב-`~/.local/share/claudephone/agent/config.json`:
```
"tunnel": { "mode": "none", "publicUrl": "https://claude.example.co.il" },
"phoneServer": { "path": "/yemot-<מחרוזת אקראית>" }
```
ואז `systemctl --user restart claudephone`.

## מה שונה מ-Windows
- אין Claude Desktop רשמי ללינוקס, ולכן אין המשך של שיחות Cowork. שיחות Claude Code רגילות עובדות.
- בשרת בלי מסך: "פתח בטרמינל", "פתח תיקייה" ובחירת תיקייה בחלון אינם זמינים, ומופיעה הודעה שמסבירה למה. את תיקיית הפרויקטים כותבים ידנית.
- אם מתקינים את גיבוי התמלול (ivrit-ai), Python מותקן בתוך תיקיית התוכנה (לא נוגע ב-Python של המערכת).

## רשימת בדיקות
סמן כל שורה אחרי שבדקת. אם משהו לא עובד, שלח את השורה שנכשלה ואת 30 השורות האחרונות ביומן (`tail -n 30 ~/.local/share/claudephone/agent/data/agent.log`).

### כבר נבדק (שרת Ubuntu 24.04 בלי מסך)
- התקנה מהקובץ, אשף ההגדרה, Python + faster-whisper + מודל העברית, טעינת התמלול.
- מנהרת cloudflared, תפריט הטלפון עם קוד הכניסה, משימה אמיתית של Claude Code.
- עדכון לגרסה חדשה ששומר את ההגדרות והנתונים.

### צריך לבדוק בכל מחשב לינוקס
1. [ ] **התקנה:** הפקודה מסתיימת בלי שגיאה, ואשף ההגדרה נפתח.
2. [ ] **אשף ההגדרה:** כל השלבים ירוקים. רכיבי גיבוי התמלול (Python, faster-whisper, מודל) הם רשות; אם מסמנים אותם, ההורדה גדולה ויכולה לקחת כמה דקות.
3. [ ] **התחברות ל-Claude** מתוך האשף.
4. [ ] **חיבור לימות:** אחרי הזנת הטוקן, שלוחה 9 מתעדכנת (בלוח הבקרה: "ימות המשיח" ירוק).
5. [ ] **שיחת טלפון אמיתית:** מתקשרים לשלוחה, מקישים קוד, שולחים משימה קצרה בקול ("צור קובץ בדיקה עם המילה שלום"), ושומעים את התשובה.
6. [ ] **תמלול:** ההקלטה מתומללת נכון בעברית דרך Claude. אם הותקן הגיבוי: בהגדרות עוברים ל-ivrit-ai ובודקים גם אותו.
7. [ ] **צינתוק** כשהמשימה מסתיימת.
8. [ ] **עלייה עם הפעלת המחשב:** מפעילים מחדש את המחשב, ובלי להיכנס לכלום מתקשרים לשלוחה. התוכנה צריכה לענות. (אם לא: בודקים `systemctl --user status claudephone` ואת `enable-linger`).
9. [ ] **הפעלה מהאשף:** בשלב האחרון, "הפעלה ובדיקה", הכפתור "הפעל" מפעיל את התוכנה מחדש דרך השירות, והיא עולה תוך כחצי דקה עם המנהרה והחיבור לימות.
10. [ ] **עדכון מתוך התוכנה:** כשתצא הגרסה הבאה, "הגדרות ותקינות", "בדוק עכשיו", "עדכן עכשיו". אחרי כדקה הגרסה החדשה רצה וההגדרות נשמרו.

### צריך לבדוק רק במחשב עם שולחן עבודה
11. [ ] **קיצור דרך** "Claude בטלפון" בתפריט היישומים ובשולחן העבודה, ופותח את לוח הבקרה.
12. [ ] **"פתח בטרמינל"** בשיחה: נפתח טרמינל עם Claude Code שממשיך את השיחה.
13. [ ] **"פתח תיקייה"**: נפתח מנהל הקבצים בתיקיית השיחה.
14. [ ] **בחירת תיקייה בחלון** (תיקיית פרויקטים חדשה): נפתח חלון בחירה.
15. [ ] **Claude in Chrome:** אם התוסף מותקן ב-Chrome בלינוקס, מפעילים אותו בכרטיס החיבורים ושולחים משימה "פתח את example.com ותגיד מה הכותרת".

### צריך לבדוק רק בשרת
16. [ ] **גישה מרחוק:** פקודת ה-SSH שההתקנה הדפיסה פותחת את הלוח מהמחשב שלך.
17. [ ] **arm64** (למשל שרת Oracle Ampere או Raspberry Pi 64 ביט): ההתקנה בוחרת את הקובץ הנכון והכל עובד.
18. [ ] **כתובת ציבורית משלך** (שרת עם דומיין): אחרי הבחירה באשף ו-reverse proxy, השלוחה עונה בלי מנהרה, והשורה "כתובת ציבורית" בלוח ירוקה.
